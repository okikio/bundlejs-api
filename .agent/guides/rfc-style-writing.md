# RFC-Style Writing Guide

## Template

1. Title
2. Summary (3–5 bullets)
3. Problem
4. Goals / Non-goals
5. Constraints (runtime, latency, compatibility, security)
6. Proposal (with diagrams)
7. Alternatives considered (why not)
8. Edge cases & failure modes
9. Observability (logs/metrics/traces)
10. Rollout plan
11. Open questions

## Tips

- Prefer concrete examples over abstract statements.
- Call out trade-offs explicitly.
- Keep “decision points” obvious.
