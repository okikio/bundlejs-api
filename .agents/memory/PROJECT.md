# Project Summary

## Outcome
Provide a concise, shared description of what this repository delivers.

## Context
This repo hosts bundlejs-api, a Deno v2 + TypeScript service for bundle size analysis, backed by esbuild (WASM) and Hono on Supabase Edge Functions.

## Constraints
- Edge runtime constraints apply to API endpoints.
- Avoid hidden global state and top-level side effects.
- Keep public APIs well-documented and verifiable.

## Non-goals
This file is not a full architecture spec or onboarding guide.

## Approach
Keep this summary short and update it only when the product shape changes.
