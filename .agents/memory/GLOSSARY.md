# Glossary

- **RFC 7807** — Problem Details JSON format for API errors.
- **TSA** — Template Strings Array. The frozen array of string literals passed
  as the first argument to a tagged template function.
- **TSDoc** — TypeScript documentation comment format (`/** ... */`) used by
  `deno doc`.
- **JSR** — Jsr.io, the TypeScript-native package registry for Deno.
- **ADR** — Architecture Decision Record. A short document capturing a
  significant design choice, its context, and the rationale.
- **CDN** — Content Delivery Network. In this codebase, refers to the CDN
  resolution plugin that fetches packages from npm-compatible CDNs.
- **VFS** — Virtual File System. In-memory filesystem used during esbuild
  bundling to avoid disk I/O.
- **WASM** — WebAssembly. esbuild runs as a WASM module in the edge runtime.
