# Review Checklist

## Correctness
- [ ] Behavior matches the stated intent.
- [ ] Edge cases and error paths are handled explicitly.

## Safety
- [ ] Secrets are not logged or stored.
- [ ] Trust boundaries are clear.

## Maintainability
- [ ] Naming is clear and consistent.
- [ ] Complex logic is explained with comments or diagrams.

## Verification
- [ ] Tests or verification steps are adequate.
